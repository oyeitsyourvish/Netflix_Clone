# 🎬 iVishMovies

A Netflix-style movie streaming website built with ASP.NET Core MVC.

## ✨ Features

- 🎬 Movie Listing
- 🔎 Search Movies
- 📋 My List
- 🔐 User Authentication
- ⭐ Movie Ratings
- 🎥 Movie Details

## 🛠️ Technologies

- .NET 8
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML5
- CSS3
- JavaScript
- Bootstrap
